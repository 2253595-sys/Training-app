# Training-app

«Боец» — персональный трекер тренировок: плечи, спина и руки, зал, офис и утренняя зарядка. Это PWA: откройте сайт в Chrome на Android и добавьте его на главный экран. Прогресс хранится на телефоне.

https://2253595-sys.github.io/Training-app/

После публикации откройте ссылку в Chrome (не во встроенном браузере мессенджера): меню → «Установить приложение» или «Добавить на главный экран».
